Deadly Days: Roadtrip - Online Co-op Mod
========================================

Unofficial fan project, not affiliated with Pixelsplit or the publisher.
Every player needs their own copy of the game on Steam.

Requirements
------------
- Windows, game installed through Steam.
- Game build 26495302. The installer rejects other builds,
  and the mod disables itself on them.
- The game is closed.

Install
-------
1. Extract the ZIP file completely into any folder.
2. Double-click Install.cmd. The game folder is found through Steam.
   If the game is elsewhere:  Install.cmd -GameDir "D:\Games\Deadly Days Roadtrip"
3. Start the game normally from Steam.

Remove
------
Double-click Uninstall.cmd. Logs and settings stay in the DDCoop folder
next to the game exe; with  Uninstall.cmd -Purge  it is deleted too.

What the installer changes
--------------------------
Only two files in DDSurvivors\Binaries\Win64 in the game folder:
  version.dll           starts the mod
  DDCoop\DDCoop.dll     the mod itself
Savegames, Steam settings and other game files stay untouched.
A version.dll from another mod is never overwritten.

Antivirus and Steam Deck
------------------------
Some antivirus programs consider the mod suspicious because it loads
through version.dll. Checksums are in SHA256SUMS.txt. Never turn off
your antivirus completely. Steam Deck and Proton are not supported.

Detailed guide and help with error messages:
